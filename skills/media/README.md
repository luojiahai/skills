# Media

Skills for keeping copies of things you'd otherwise lose.

**User-invoked**

- **[douyin-downloader](./douyin-downloader/SKILL.md)** — download every video from a Douyin account, or a single video, into `./downloads/`. Re-runs fetch only what is new, so an account can be re-archived on a schedule without re-downloading what you already have. *Needs [yt-dlp](https://github.com/yt-dlp/yt-dlp), Node, and a one-off Douyin sign-in you do yourself.*
