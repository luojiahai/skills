# skills

Claude Code skills, one directory each under [`skills/`](skills).

| Skill | What it does | Install |
|---|---|---|
| [`lodge-au-tax-return`](skills/lodge-au-tax-return) | Prepare an Australian individual tax return for self-lodgement in myTax — reconcile prefill, test every deduction, and produce a label-by-label worksheet. *Not tax advice — see [the skill's README](skills/lodge-au-tax-return).* | `claude plugin install lodge-au-tax-return@luojiahai` |

## Install

```sh
claude plugin marketplace add luojiahai/skills
claude plugin install <skill>@luojiahai
```

Each skill's README covers the other install paths and how to run it.
